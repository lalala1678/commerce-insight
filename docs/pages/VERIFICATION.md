# 静态演示本地验收

执行日期：2026-09-25。此记录只覆盖本地构建及离线预览；GitHub Actions 和线上地址另由远程运行结果验收。

| 检查 | 结果 |
|---|---|
| 真实数据导出 | 7 个预设范围；`options.json` + 各范围日/周/月、客户、报告共 36 个 JSON，加哈希清单共 37 个文件，合计 1,118,491 字节 |
| 完整性与隐私 | `python -m pytest tests/test_static_export.py -q`：18 passed；清单 SHA-256、范围、版本、金额、订单、客户一致；递归拒绝订单、客户、评价文本及地址类字段；接口新增未审核的顶层字段时停止导出 |
| 本地 API 一致性 | `python -m scripts.verify_static`：7 个范围 × 5 类响应共 35 次 FastAPI 比对通过；报告仅排除每次生成都会变化的时间戳及含它的模板正文，新加的任务卡仍逐字段参与比对 |
| 长观察窗 RFM | 2018-02-01 至 2018-07-31：38,560 位窗口购买客户，R>30 天 32,460 位、R≤30 天 6,100 位；另以仓库表的独立 SQL 聚合得到相同结果。仅覆盖窗口购买者，不识别全部流失客户 |
| 前端构建 | `VITE_STATIC_DEMO=1 npm run build`：退出码 0，静态资源路径为 `/commerce-insight/`；主包约 912 KB，存在构建器体积提醒 |
| 浏览器 | Edge 无头预览，1440×1000 与 390×844：四页、预设切换、最近完整周、趋势粒度、报告 JSON 下载通过；长观察窗显示 38,560 位客户、32,460 位 R>30 天客户和四个 R>30 分组；手机页面整体水平溢出 0px |
| 网络与错误 | 浏览器过程无 `/api/` 请求、无页面异常、无 HTTP 4xx/5xx；静态版不显示订单明细入口 |
