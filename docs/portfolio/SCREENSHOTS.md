# 页面截图索引

以下是本地完整版本的真实 Olist 历史数据验收截图。它们记录的是各阶段通过浏览器检查时的页面，并非已经发布的 GitHub Pages 截图。在线静态版上线后应另存发布截图，避免把本地界面当作线上证据。

| 页面 | 桌面截图 | 手机截图 | 适合说明什么 |
|---|---|---|---|
| 经营概览 | [查看](../core/overview-desktop.png) | [查看](../core/overview-mobile.png) | 已交付商品金额、订单数、客单价、趋势与日期筛选 |
| 商品与履约 | [查看](../core/products-desktop.png) | [查看](../core/products-mobile.png) | 商品排名、交付与评价分母、订单明细入口 |

| 经营报告 | [查看](../reports/desktop.png) | [查看](../reports/mobile.png) | 同期比较、贡献拆解、异常提示、报告导出 |
| 单独导出的 HTML 周报 | [查看](../reports/html-preview.png) | — | 离开平台仍可阅读的固定模板报告 |

推荐对外展示顺序：概览 → 商品与履约 → 客户分析 → 经营报告 → HTML 周报。需要解释数值时同时打开 [口径文档](../METRICS.md) 和 [销售案例](../reports/CASE_SALES.md)，不要只展示图片。

原图在 `docs/core/`、`docs/customers/`、`docs/reports/`。其中经营报告手机截图使用 2017-11-20 至 11-26 的异常示例，桌面截图使用 2018 年 7 月；两张不是同一筛选条件。
