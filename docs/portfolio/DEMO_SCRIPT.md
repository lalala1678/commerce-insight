## 演示前检查

1. 核对[截图索引](SCREENSHOTS.md)与数据版本。长观察窗截图为 `2018-02-01` 至 `2018-07-31`、全部品类与地区，视频中的 38,560、747、32,460、R$ 1,063,516.76 和履约评分来自这一范围；7 月单月的 6,159、R$ 867,953.46、+1.39%／-1.88% 不可挪到长观察窗。
2. 在线 GitHub Pages 只提供已导出的预设范围；若改为现场操作，可使用本地完整版本。现场录屏前隐藏个人账户、本地绝对路径和终端凭证，不在公开视频聚焦逐单 ID。
3. 导出视频后验证片长恰好 180 秒、无音轨、关键字幕可读；末尾保留 Olist 来源、CC BY-NC-SA 4.0 和未实施建议的边界。不要把截图视频称为在线操作录屏或配音视频。
