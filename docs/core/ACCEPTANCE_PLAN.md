# 第 2–4 周验收范围

本轮只实现真实数据 ETL、共用指标 API、经营概览、商品与履约页面、筛选和订单明细。
不提前实现 RFM、新老客、预测、自动报告或 GitHub Pages。

## 必须通过的检查

1. 真实数据全部入库：订单 99,441，商品项 112,650；已交付订单 96,478，商品金额 1,322,149,811 分（BRL）。
2. 对同一数据连续导入两次，表行数、金额、聚合值不变，不新增重复业务记录。
3. 商品、支付、评价独立处理到订单粒度；多商品、多支付、多评价样例仍符合手算金额与订单数。
4. 校验失败或数据库写入失败时，不留下半套分析表；此前有效数据仍可读取。
5. 1 笔已交付缺支付订单保留商品销售；支付金额为 null。8 笔缺送达日期订单不进入相应履约分母。
6. 独立读取原始 CSV，核对全部已交付、2018-07、品类＋地区交集、2018-06 RJ、空筛选和带引号筛选。
7. 核对 SQL 事实表、日汇总表、API 的金额和订单数一致；分页无重叠，订单明细品类金额与列表一致。
8. 桌面与手机页面可读；应用日期/品类/地区筛选后所有已展示数字一致；页面错误不保留冒充当前结果的旧数字。
9. 空筛选不报错；0 订单时客单价、延迟率和平均评分不可计算；边界周/月标明不完整，未知范围不画成已证实的零。
10. API 参数错误返回 422，未导入返回 503，未知订单返回 404；查询条件使用绑定参数。
